DOM mai New Element Create Karna 📌
            DOM mein naya element banane ke liye document.createElement() use karte hain.

Syntax
const element = document.createElement("tagName");


Example:
Agar humein naya <li> banana hai:
                    const li = document.createElement("li");

Ab li element create ho gaya, lekin abhi webpage par nahi aaya hai.

Usme text add karo:  li.innerText = "Five";

Ab DOM mein add karo:
                    document.querySelector("ul").appendChild(li);


Complete Example
const li = document.createElement("li");

li.innerText = "Five";

document.querySelector("ul").appendChild(li);


Agar pehle:
            <ul>
                <li>One</li>
                <li>Two</li>
            </ul>

Tha, to baad mein:
            <ul>
                <li>One</li>
                <li>Two</li>
                <li>Five</li>
            </ul>


Important Flow 🔥
createElement()
      ↓
New element create
      ↓
Content / attributes add
      ↓
appendChild()
      ↓
DOM mein add



Yaad rakho:
                document.createElement("li")
                → new <li> banata hai

                parent.appendChild(child)
                → us child ko DOM mein add karta hai.

---------------------DOM – Creating New Element 📒----------------------------
1. createElement()
const div = document.createElement('div');

Meaning: JavaScript ki help se ek naya <div> element create karna.

⚠️ Important:
Sirf create hua hai, abhi webpage par visible nahi hai.


document
   ↓
createElement('div')
   ↓
New <div> created
   ↓
DOM mein abhi attach nahi hua





2. className
div.className = "main";

Naye <div> ko class de raha hai:

<div class="main"></div>




3. id
div.id = Math.round(Math.random() * 10 + 1);
Ye randomly ID generate karta hai.


Example:
<div class="main" id="7"></div>

Breakdown:
Math.random()
→ 0 se 1 ke beech random number.

Math.random() * 10   → 0 se 10 ke beech.

Math.random() * 10 + 1   → 1 se 11 ke around.

Math.round(...)   → nearest integer.








4. setAttribute()
div.setAttribute("title", "generated title");

Element mein attribute add karta hai.

Result:
<div class="main" id="7" title="generated title"></div>

Syntax:
element.setAttribute("attribute", "value");

Example:
div.setAttribute("title", "Hello");
div.setAttribute("data-id", "123");








5. style
div.style.backgroundColor = "green";
div.style.padding = "12px";

Naye element ki CSS set kar raha hai.

Result:

Background → green
Padding → 12px






6. createTextNode() ⭐
const addText = document.createTextNode("Chai aur code");

Ye text node create karta hai.

Result conceptually:
"Chai aur code"
       ↓
   Text Node

Lekin abhi ye bhi webpage par nahi hai.







7. appendChild() ⭐⭐⭐
div.appendChild(addText);

Ab text node ko div ke andar add kar diya.

Before:  <div class="main"></div>

After:   <div class="main">Chai aur code</div>


Simple meaning:
appendChild() kisi child node ko parent ke andar add karta hai.








8. Finally document.body.appendChild()
document.body.appendChild(div);

Ye sabse important step hai.
Ab jo <div> JavaScript se banaya tha, usko actual webpage ke <body> mein attach kar diya.

Final HTML:
<body>
    <div class="main" id="7" title="generated title">
        Chai aur code
    </div>

</body>

Ab element browser mein visible hoga. 👀

1. Existing Element ke saath kaam

Agar element HTML mein already present hai, to:

SELECT
  ↓
TRAVERSE
  ↓
MODIFY
  ↓
REMOVE (if needed)


Example:
const parent = document.querySelector('.parent');


SELECT
document.querySelector()
document.getElementById("id")
document.querySelector(".class")
document.querySelectorAll(".class")
→ HTML element ko find karta hai.



TRAVERSE
parent.children
parent.firstElementChild
parent.lastElementChild
child.parentElement
child.nextElementSibling
→ DOM tree mein idhar-udhar move/access karte hain.





MODIFY
element.innerText = "Hello";
element.textContent = "Hello";
element.innerHTML = "<b>Hello</b>";
element.style.color = "red";
element.setAttribute("title", "Hello");
→ Element ka content, CSS, attributes change karte hain.




REMOVE
element.remove();
→ Element ko DOM se hata dete hain.




2. New Element ke saath kaam ⭐
Agar element HTML mein nahi hai aur JavaScript se banana hai, to flow:


CREATE
   ↓
CUSTOMIZE
   ↓
ADD CONTENT
   ↓
APPEND TO DOM



Step 1 → Create
const div = document.createElement("div");

➡️ Naya <div> create hua.

⚠️ Abhi webpage par visible nahi hai.




Step 2 → Customize
div.className = "main";
div.id = "box";
div.style.backgroundColor = "green";
div.style.padding = "12px";

➡️ Class, ID aur CSS add ki.




Step 3 → Add Content
const text = document.createTextNode("Chai aur Code");

div.appendChild(text);

➡️ Text ko <div> ke andar add kiya.

Ab:

<div class="main" id="box">
    Chai aur Code
</div>





Step 4 → Append to DOM ⭐
document.body.appendChild(div);

➡️ Ab <div> ko actual webpage ke <body> mein add kiya.

Ab browser par element dikhega.






🧠 Final Flow — Ye zaroor yaad karna
                 DOM MANIPULATION
                       ↓
              ┌────────┴────────┐
              ↓                 ↓
       EXISTING ELEMENT     NEW ELEMENT
              ↓                 ↓
           SELECT             CREATE
              ↓                 ↓
          TRAVERSE          CUSTOMIZE
              ↓                 ↓
           MODIFY          ADD CONTENT
              ↓                 ↓
           REMOVE         APPEND TO DOM
                                ↓
                           WEBPAGE UPDATE
🔥 Ek line mein:

Existing Element: Select → Traverse → Modify → Remove

New Element: Create → Customize → Add Content → Append to DOM
