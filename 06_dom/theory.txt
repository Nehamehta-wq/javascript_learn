                                                **DOCUMENT OBJECT MODEL (DOM)**
The DOM (Document Object Model) is a programming interface that represents an HTML or XML document as a tree of objects. 
JavaScript uses the DOM to access and modify the content, structure, and style of a web page.

Example HTML:
                        <!DOCTYPE html>
                        <html>
                        <head>
                            <title>My Page</title>
                        </head>
                        <body>
                            <h1 id="heading">Welcome</h1>
                            <p>This is a paragraph.</p>
                            <button>Click Me</button>
                        </body>
                        </html>

DOM Tree:
                        Document
                        │
                        └── html
                            ├── head
                            │   └── title
                            └── body
                                ├── h1
                                ├── p
                                └── button

Each HTML element becomes an object (node) that JavaScript can manipulate.

document.getElementById()
ID se ek element select karta hai.

example:
                   => <h1 id="title">Hello</h1>

                   => const heading = document.getElementById("title");

                   => console.log(heading); // <h1 id="title">Hello</h1>


document.getElementById("title").id
                    Output:
                    "title"
                    Kyunki id ek direct DOM property hai.


document.getElementById("title").class
                    Output:
                    undefined
                    Kyunki JavaScript DOM mein class naam ki property nahi hoti. 
                    class JavaScript keyword bhi hai, isliye browser className use karta hai.
document.getElementById("title").className
                    Output:
                    "heading"

                                Modern aur better approach:
const title = document.getElementById("title");

title.classList.add("active");          // class add
title.classList.remove("heading");      // class remove
title.classList.toggle("dark");         // on/off class

            Attribute ko generic tareeke se read karne ke liye:
            title.getAttribute("id");       // "title"
            title.getAttribute("class");    // "heading"
            title.getAttribute("data-id");  // null, agar attribute exist nahi karta



Attribute set/remove:
title.setAttribute("title", "Main heading");
title.setAttribute("class", "heading active");
title.removeAttribute("title");



            Difference yaad rakho:
            title.id                 // direct property
            title.className          // class ki string
            title.classList          // classes manipulate karne ka object
            title.getAttribute("class") // HTML attribute ki value



Most practical usage:
const title = document.querySelector("#title");



            title.textContent = "Updated heading";
            title.style.color = "orange";
            title.classList.add("highlight");
            title.setAttribute("data-topic", "dom");



getAttribute() ko image mein aage aise complete karna hai:

textContent element ke andar ka plain text read ya change karta hai.

const title = document.getElementById("title");
console.log(title.textContent); // "DOM learning on Chai aur code"




Text change karne ke liye:
                title.textContent = "Hello JavaScript";




Agar HTML tags bhi text ki tarah dikhane hain:
                title.textContent = "<span>Hello</span>";         
                Page par literally yeh dikhega:
                        <span>Hello</span>
                        textContent safe hai, kyunki HTML parse nahi karta.




Quick comparison:
title.textContent  // plain text
title.innerHTML    // HTML tags ke saath content
title.innerText    // visible text, CSS visibility consider karta hai
            Example:
            <h1 id="title">
            Hello <span style="display:none">Hidden</span>
            </h1>
            title.textContent; // "Hello Hidden"
            title.innerText;   // "Hello"
            title.innerHTML;   // 'Hello <span style="display:none">Hidden</span>'

querySelector() is a JavaScript method used to select the first HTML element that matches a specified CSS selector.
querySelector() sirf first matching element return karta hai.


Syntax
document.querySelector(selector);

Examples
1. ID se element select karna
        HTML
        <h1 id="heading">Hello JavaScript</h1>

        JavaScript
        let element = document.querySelector("#heading");

        console.log(element);
        console.log(element.textContent);

                                Output
                                <h1 id="heading">Hello JavaScript</h1>

                                Hello JavaScript


2. Class se element select karna
        HTML
        <p class="message">Hello</p>
        <p class="message">Welcome</p>
        <p class="message">JavaScript</p>

        JavaScript
        let element = document.querySelector(".message");

        console.log(element);
        console.log(element.textContent);

                                Output
                                <p class="message">Hello</p>

                                Hello



3. Tag name se select karna
        HTML
        <h1>Heading 1</h1>
        <h1>Heading 2</h1>

        JavaScript
        let heading = document.querySelector("h1");

        console.log(heading);
        console.log(heading.textContent);

                                Output
                                <h1>Heading 1</h1>
                                Heading 1



4. ID + Class : CSS ki tarah multiple conditions bhi de sakte ho.

        HTML
        <p id="para" class="text">Hello World</p>

        JavaScript
        let element = document.querySelector("#para.text");

        console.log(element.textContent);

                                Output
                                Hello World




5. Nested elements

HTML
        <div class="container">
            <p>Hello</p>
            <p>Welcome</p>
        </div>

        <div class="box">
            <p>JavaScript</p>
        </div>


        let element = document.querySelector(".container p");
        console.log(element.textContent);

        
                                    Output
                                    Hello
